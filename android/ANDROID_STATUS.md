## Current objective

Produce the smallest Android foundation that proves:

- app starts;
- diagnostic session initializes;
- structured events can be written locally;
- important foundation actions are correlated;
- diagnostics can be exported by explicit user action;
- guided testing can verify actual foundation behavior;
- product-owned engine interfaces exist without requiring an AI engine yet.

## Not implemented yet

Live/video/image input, motion analysis, AI object detection, tracking, plate/OCR processing, zones/tripwires, event history/search, recording, and multi-camera scheduling are not yet implemented and must not be presented as working.
