Cross-platform local-first surveillance/computer-vision platform.

- Repository: `auxz2jz/Slot-16`
- Project type: cross-platform
- Android: active development
- Windows: not started

- Current phase: Foundation 0A

## Ownership

- `shared/` contains platform-neutral product requirements and interfaces.
- `android/` is owned by the Android development worker.
- `windows/` is reserved for the Windows/PC implementation and must not be modified by Android development except for a minimal handoff placeholder.

## Master instructions

Before development, read `auxz2jz/master-instruction-library/INSTRUCTION_INDEX.md` and all mandatory files it references.

Normal workflow:

READ → PLAN → RECORD PLAN → CHECKPOINT → MODIFY → BUILD → TEST → ANALYZE → RECORD RESULT → CHECKPOINT → CONTINUE
